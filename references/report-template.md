# 体检报告模板

必须用这个格式，中文输出。没检查过的项不要编，写「未检查」或「无法验证」。

```
═══════════ 技能体检报告 ═══════════
技能名：
来源：（ClawHub / GitHub / 自建 / 其他）
版本：
类别：（①办公 ②写作 ③研究 ④视频 ⑤设计 ⑥游戏 ⑦翻译 ⑧数据 ⑨笔记 ⑩工程 ⑪元技能）
───────────────────────────────
【结构】
  SKILL.md 位置：   ✅ 根目录 / ❌ 套了一层
  正文规模：        ___ 行 / 约 ___ token（建议 ≤500 行 / 5000 token）
  目录构成：        （列出 scripts/references/assets 及文件数）
  垃圾文件：        （无 / 列出）
  孤儿文件：        （无 / 列出未被引用的文件）
  断链 / 未闭合代码块：（无 / 列出）

【frontmatter】
  name 格式：       ✅ / ❌（说明）
  与文件夹同名：    ✅ / ❌
  触发方式：        🤖 自动 / ✋ 手动
  description：     ___ 字符（上限 1024）  ✅ / ❌
  关键词堆砌：      ✅ 无 / ⚠️ 有（说明）

【安全】
  网络请求：        （无 / 列出域名）
  凭证读取：        （无 / 列出）
  危险执行：        （无 / 列出）
  误报说明：        （看似危险实为示例的，说明）
  红旗判定：        ✅ 无 / ⚠️ 需注意 / ❌ 拒绝安装

【兼容性】
  DSH：             ✅ / ⚠️ / ❌（原因）
  ZCode：           ✅ / ⚠️ / ❌（原因）
  Claude Code：     ✅ / ⚠️ / ❌（原因）
  Codex：           ✅ / ⚠️ / ❌（原因）
  其他平台：        （说明 / 未实测）

【冲突】
  重名：            （无 / 与 X 重名）
  抢触发：          （无 / 与 X 重叠，建议……）

【依赖】
  外部命令：        （无 / 列出，是否已安装）
  环境变量：        （无 / 列出，是否已配置）
  平台专有能力：    （无 / 列出，换平台会失效）

───────────────────────────────
风险等级：🟢 低 / 🟡 中 / 🔴 高 / ⛔ 极端
结论：✅ 可以装 / ⚠️ 装了要改 / ❌ 不要装
建议动作：
  1. （具体到改哪一行 / 删哪个文件 / 装到哪个目录）
  2. …
═══════════════════════════════
```

## 风险分级

| 等级 | 特征 | 处理 |
|---|---|---|
| 🟢 低 | 纯 Markdown，无脚本，无网络 | 看过即可装 |
| 🟡 中 | 有脚本 / 网络请求 / API 依赖 | 逐行看脚本，确认网络目标 |
| 🔴 高 | 碰凭证 / 改系统文件 / 要提权 | 必须用户明确同意 |
| ⛔ 极端 | 改安全配置 / 要 root / 混淆代码 | 直接拒绝 |
